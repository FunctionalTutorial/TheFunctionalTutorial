> **Caveats**
>
> - Steam’s guide listing is JS-hydrated; this inventory was assembled via search + author workshop pages + individual guide fetches, not a guaranteed complete scrape of every guide ever posted.

## 3. Findings useful for job tutorials (by department)

### 3.1 Onboarding / shared fundamentals

From **New Player Guide** and **Основы игры**:

- Character customize → job preference panel (None → High); latejoin often lands Passenger.
- Rules / ahelp / F1 guidebook; IC vs OOC; no intents system (harm mode button instead of SS13 intents).
- Traitor: press **C** for objectives; buy gear from PDA uplink; do not treat antag as free RDM for non-antags.
- Department one-liners useful for tutorial “pick a job” screens:
  - **Sec:** uphold space law, proportional nonlethals, brig.
  - **Eng:** power, repairs, atmos.
  - **Med:** heal, surgery/clone (era-dependent), chemistry.
  - **Cargo:** orders + salvage.
  - **Service:** feed/clean/entertain; clown/mime are still crew.

**Tutorial takeaway:** short “what this job is for” blurbs + “ask HoP for access / ask seniors on radio” beats dumping full rules.

### 3.2 Engineering & Atmospherics

From **An Evolving Guide to Station Power** (Wizden-targeted):

**Gear checklist for tutorials**

- Eng/Atmos hardsuits + magboots; welding eye protection; utility belt (crowbar, wrench, screwdriver, wirecutters, welder, multitool); RCD + compressed matter; fireaxe (Atmos).
- Wire tiers: LV / MV / HV; crowbar opens unpowered airlocks; wirecutters/multitool for door hacks; alt-click lock emitters.

**Power progression (tutorial steps)**

1. **AME** — place flatpacks ≥3×3; surrounded shielding becomes cores; fuel jar in controller; controller on **HV**; injection ≤ **2× core count**.
2. **Containment** — emitters (MV) + field gens; prefer 4 emitters / 4 gens; lock emitters; PA power typically **2**.
3. **Singulo** — rad collectors + plasma canisters; keep PA feeding; escape → decelerator / starve / hope it drifts.
4. **Tesla** — coils for HV; grounding rods protect equipment; mini-balls from PA/electronics; escape → evacuate (hard to recover).
5. **TEG** — hot/cold loops must not mix; flow direction follows circulator arrows; typical mix ~97–98% plasma / 2–3% O₂; volumetric vs gas pumps; space radiators for cold loop; pressure lockout → vent; pipe burn → evacuate pipes to 0 kPa.

**Tutorial takeaway:** split into micro-tutorials: *AME safe start* → *PA chamber containment* → *Singulo vs Tesla choice* → *barebones TEG*. Emphasize “ask for help; even antags often want power on.”

From **Отдел Инженерии (RU):** door tech panels (screwdriver + wire tools), material logistics, TA vs Atmos vs CE role split — good for role-picker descriptions.

From **Тритий и фрезон (outdated):** air alarm scrubber address filtering for Frezon production — only useful as “advanced atmos elective,” verify against current mechanics.

### 3.3 Medical

From **Intro to Paramedic**:

- Mission: find → stabilize → transport to medbay (full treatment secondary).
- Find patients via **crew monitor** (crit/dead/coords); radio callouts; check disposals + maints lockers for hidden bodies.
- Ask HoP for **externals** access for spaced patients.
- Stabilize: epen / epi (~5u repeated); treat top damage type if syringes ready; gauze for bleed; body bag for dead (prevent rot) → stasis / morgue.
- Suggested kit: rollerbed, syringes (Bic/Dylo/Derm or Bru/Punc/Lace), epi offhand, body bag, crowbar, wrench, large O2/N2 tank, MedVend extras.
- Don’t defib in field if you can’t stabilize for the ride.

From **Отдел Медицины (RU):** role matrix (Intern, Doctor, Psychologist, Chemist, Paramedic, CMO, Medical borg, Virologist) with duty checkmarks — excellent structure for a med department tutorial tree.

From **chemistry guides** (Joey Strumm + Recipes):

**Workflow tips for Chemist tutorials**

- Label with short prefixes (labeler char limit).
- Transport beakers/jugs in bags (drop = spill/break).
- Drag containers into ChemMaster; stash finished meds in locked med lockers (bag-in-locker resists bomb spills).
- Split work with second chemist: “advanced brutes vs plasma path.”
- Priority ladder: basic mixes → plant meds → plasma → cryo → heat (hotplate) → specials.
- Coordinate botany for thistle/aloe/ambrosia; cargo/eng for plasma.

**Core meds commonly taught**

| Med | Rough purpose | Notes for tutorials |
|---|---|---|
| Bicaridine | Brute | Early basic |
| Dermaline | Burn | Early basic |
| Dylovene | Poison | Early basic |
| Inaprovaline | Airloss / stabilize | Safe starter |
| Tricordrazine | Mixed | Dylo + Ina |
| Bruizine / Lacerinol / Puncturase | Advanced blunt/slash/pierce | Heat path |
| Dexalin Plus | Airloss | Plasma catalyst |
| Cryoxadone / cryo suite | Cryo pod | Temp constraint |
| Omnizine | Mixed | Botany mutation |
| Ambuzol(+)| Zombie | Special event |

**Tutorial takeaway:** teach machine loop (Dispenser → mix → ChemMaster → pill/bottle → deliver) before dumping full recipe tables; link recipes as reference, not first lesson.

### 3.4 Science

From **Chemistry n' Science 4 Newbies** (dated) + **Отдел РнД**:

- Early research priorities called out historically: Basic Parts, Material Printing, Industrial Engineering, Chem/Medical tech → build cloning/scanner/chem machines.
- RnD roles: Research Assistant, Scientist, RD.
- Cross-dept: cloning/chem machines help med; industrial grinder / hydro tech helps botany; boards help cargo money loops.

**Tutorial takeaway:** “first 10 minutes of R&D” tutorial (console → unlock → lathe boards for med/cargo) is more valuable than artifact deep-dives for new players.

### 3.5 Cargo / Salvage / QM

From **Отдел Карго**:

**Cargo Tech**

- Dock supply shuttle at shift start; appraisal tool in pocket.
- Early money: haul unanchored tanks from maints onto shuttle sell pads (**never** steal food/water vendors or crew essentials).
- Mid-round money: Autolathe/Protolathe board spam (door boards called out as profitable); Frezon/Tritium canisters from atmos if available.
- Order priority: heads / station-critical (AME fuel, eng/sci mats, sec weapons in crisis) over clown pig crates.

**Salvage**

- Gear: salvage hardsuit, magboots, PKA, pickaxe, ore bag, GPS, drill (research), jetpack (buy).
- Magnet pulls wrecks; mass scanner for positions; loot engines/artifacts; asteroids for ore.
- Expeditions: timed FTL missions (kill boss / destroy structures); modifiers (bad atmos, darkness, short timer); prepare guns/meds/food.

**QM**

- Own order approval; brief department; don’t hire random greytide as salvage without screening; be station’s logistics lead, not “Cargonia” without antag/justification.

From **Sadler shuttle guide** (construction transferable to salvage/cargo/eng):

- EVA/hardsuit + magboots ON before lattice walking; place lattice *in direction of travel*.
- Thrusters: LV power, correct nozzle facing, must face space/lattice, toggled on.
- Prefer salvaged SMES + substation for shuttle power; grid checks kill shuttle APCs.
- Don’t delay the round to build vanity shuttles.

**Tutorial takeaway:** three short tracks — *sell loop*, *wreck loot loop*, *don’t crash the supply shuttle*.

### 3.6 Service

#### Janitor (excellent tutorial source)

From **The Janitor Guide** (WizDen-specific):

- Closet (trashcan logo / green door); galoshes unique to janitors; Janibelt: wire brush, cleanades, light replacer, space cleaner, soap.
- Must grab **mop + trash bag** (+ holosign projector).
- Mop: wet from bucket → click puddles → water replaces reagents → empty bucket on drain (1000u capacity; plunger if clogged).
- **Potassium** (white/shiny) + water = explosion centered on mopper → use cleaner/cleanade carefully, not mop.
- Cleanades for large spills; Space Cleaner for dirt/graffiti; light replacer for bulbs; mousetraps for kitchen/bar; wielded mop = 15 blunt.
- Advanced mop (sci research): auto-deletes reagents, regenerates water.
- Disposals/recycler: blood-coated emagged recycler → call Sec; detective often present.

**Tutorial steps write themselves:** gear up → fill bucket → mop hallway → empty drain → replace a light → bag trash.

#### Botanist

From **How to Botany**:

- Tools: clippers (preserve genetics), hoe, spade, hatchet, plant bag, Robust Harvest (≤50 potency), EZ Nutrients, mutagens from chem.
- Tray lights: green harvest / red dying / red circle environment / orange nutrients / blue water.
- Clip after Robust Harvest; seed extractor for mass seeds; industrial grinder (research) for chem scaling.
- Serve chef (food), chem (reagents), cargo (bounties).

#### Chef

From **How to Chef**:

- Goal: feed station; pizzas/cakes scale well with botany help.
- Beaker prep for batters/mixes; eggs have variable reagent amounts — check grinder.
- Full recipe lists exist but go stale — tutorial should teach *machines + patterns*, then point to guidebook/wiki.

#### Bartender

From **Bartending 4 Newbies**:

- Roundstart: Booze Storage shotgun → glasses into Booze + Soda dispensers.
- Know exits (bar is bomb magnet); optional redecorate / music / chem+chef ingredients.
- Large mixture tables (Irish Cream → Long Island → Antifreeze, etc.) + specials needing banana juice, milk, uranium, tricord, etc.
- In-game drink guidebook exists — Steam list is still good for “first shift checklist.”

#### Clown / Mime / Musician

From EN clown guides + **Клоун, мим и музыкант**:

- Prefer Clown high + Mime/Musician/Boxer backups; HoP transfer if denied.
- Good clowning: peels, soap, pies, lube — avoid grief; represent Honkmother kindly.
- Tools: bike horn, clown bag honk, foam blade, banana cream pies; chem can make space lube (water+silicon+oxygen).
- Mime: vow of silence, crayon, invisible wall ability (~30s CD); breaking vow loses wall (~5 min to restore).
- Musician: MIDI files; request synth/music station from RnD.

#### Librarian

From librarian hub: book bag (30 books), briefcase, blank book + pen, hand labeler (Z to name), d10; fax for distributing writing; tabletop games guide linked.

### 3.7 Security

From **Отдел Службы безопасности** (best Sec content found on Steam):

- **Cadet:** help Warden (brig-bound); stay with assigned officer; logistics/medevac, not frontline.
- **Officer:** arrests; nonlethals (flash/baton stamina) key; Shift+E belt smart-equip; on red, lethal only vs confirmed threats; deliver to Warden for sentencing.
- **Arrest triggers:** witnessed crime / Sec radio / ≥3 complainants → ask to come to brig → stun/cuff if resists.
- **Detective:** fingerprint/fiber scanner; glove fiber types hint department; can compel prints; ask Capt/HoP for access.
- **Warden:** sentencing, brig timers, armory control (hand out gear personally on red — no free-for-all).
- **HoS:** department leadership, Space Law, antag response.
- **Sec borg:** full access, no emotion RP, third person; refuse being used as all-access escort.

**EN gap:** no modern English Sec tutorial comparable to the RU handbook — high-value Wizden tutorial opportunity.

## 4. Patterns that transfer well into in-game tutorials

Community guides that work well share these structures — good templates for Wizden tutorial steps:

1. **Shift-start checklist** (where you spawn, what to grab, first 60 seconds).
2. **Tool identity cards** (name → what it does → where it is).
3. **Happy-path loop** (one complete work cycle: mop→drain, mix→bottle→deliver, magnet→loot→sell).
4. **One failure mode** (potassium, AME overinjection, Tesla escape, spilled beaker).
5. **Cross-department ask** (botany↔chem, cargo↔eng fuel, para↔HoP externals).
6. **“When to escalate”** (call Sec/Med/Eng; don’t solo the disaster).

Guides that work poorly as tutorial sources:

- Exhaustive recipe dumps without workflow (use as reference UI instead).
- Satire / server-drama posts (`How to Have Fun on Wizards Den`).
- Fork-specific CentCom/ERT lore presented as stock Wizden truth.
